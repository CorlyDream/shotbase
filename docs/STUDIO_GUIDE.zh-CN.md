# ShotBase 分镜工作台使用说明

这次改版专门面向「生成图片 → 在豆包网页生成视频 → 下载后导入」的工作流程。**原项目目录和素材版本文件保持不变**，无须迁移现有数据。

## 首页布局

- **高清首尾帧**：列表直接读取本地保存的原始分辨率图片，而不是放大原有的 240×180 缩略图；点击预览仍可查看原图，历史版本无需重新上传。
- **尾帧 / 生成视频 / 备用视频 / 音频**：独立素材区，保留原有功能。
- **分镜脚本**：右侧脚本预览自动填满卡片剩余高度，长文在内部滚动，不会撑大整个分镜。点击「展开全文」打开大尺寸弹窗，可查看完整脚本、修改并保存或取消。
- **制作进度**：顶部显示分镜、首帧和已生成视频数量，以及视频完成比例。
- **宽松/紧凑双模式**：默认宽松视图使用旧版「紧凑视图」的卡片间距与图片尺寸；新的紧凑视图使用矮的横向分镜条，电脑屏幕可连续浏览约 2～3 个镜头。紧凑模式中较小的素材备注框会隐藏，但版本选择、上传和分镜脚本仍能操作，切回宽松模式即可编辑素材备注。
- **紧凑视图首帧画布**：首帧改成三段式布局：顶部标题与当前版本、中间完整的 16:9 高清图片、底部横向「查看版本 / 提示词 / 备注 / 上传新版」。不再显示右侧竖排操作栏，也不强制图片拉伸成固定高度。
- **按需编辑备注**：紧凑模式默认隐藏首帧素材备注输入框，点击「备注」才展开；输入框仍使用原有的失焦/修改自动保存接口。宽松视图仍直接显示备注框。
- **节省首屏空间**：紧凑视图会压缩项目概览和镜头列表标题，不再让统计区域占用太多高度。
- **沿用布局偏好**：旧版本存储的「紧凑视图」设置仅迁移一次到新的宽松视图，避免升级后突然进入更密集的布局。之后两种模式的选择继续保存在浏览器本地。


## 分镜脚本弹窗

- 卡片里的脚本预览始终填满可用高度，不再受旧版 `295px` 上限影响；长脚本可在预览区内部滚动。
- 点击右上角 **「展开全文」**，会弹出独立的脚本编辑窗口。内容从当前卡片读入，包含尚未失去焦点的输入文本。
- 点击 **「保存脚本」**，调用原有 `POST /api/shots/notes` 接口，保存成功后同步到卡片；若接口保存失败，弹窗会保留输入内容以便重试。
- 点击 **「取消」**、右上角 **×** 或按 **Esc**，关闭弹窗并放弃弹窗内未保存的修改；卡片里此前已自动保存的内容不会被撤销。
- 素材上传、历史版本、提示词、分镜排序逻辑保持不变。

## 上传第二个、第三个版本

无需删除旧图片或视频：

1. 第一次上传之后，每个有素材的区域下方都会显示「+ 上传新版」。
2. 点击它选择新文件，或者直接把新文件拖到原素材区域。
3. ShotBase 会将新文件存储到对应分镜的 `wip` 中，并将其作为当前版本。
4. 点击「查看版本」，打开可视化版本列表。每个版本有独立缩略图/播放器和明确的版本号。
5. 点击「设为当前版本」，可随时选回旧版本，**其他历史文件不会被删除**。

点击图片左下角的 `v001` 版本角标也会打开版本列表，不再需要盲目循环切换。

如果你曾在文件管理器里手动删过 `wip` 里的文件，列表只显示现在真实存在的版本；版本号不必连续。

## 后端接口

增加两个只读接口，仍然只访问当前打开的项目：

- `GET /api/shots/versions/<shot_name>/<asset_type>`：返回当前选中版本、文件列表、预览 URL。
- `GET /api/shots/version-media/<shot_name>/<asset_type>/<version>`：读取指定历史版本的图片、视频或音频文件。

支持的素材类型为 `first_image`、`last_image`、`video`、`alt_video` 和 `audio`。文件名与路径经过校验，不支持访问项目外的路径。

## 运行和验证

```bash
uv sync
uv run run.py
```

然后打开 http://127.0.0.1:5001 。

运行回归测试和 JS 语法检查：

```bash
uv run python -m unittest discover -s tests -v
uv run ruff check app/routes/version_routes.py app/__init__.py tests/test_version_gallery.py
node --check app/static/js/studio.js
```

## 兼容性

仍使用原有的 `/api/shots/upload` 和 `/api/shots/promote`；没有修改现有文件格式、上传规则、导出流程、分镜排序或历史版本的命名规则。
